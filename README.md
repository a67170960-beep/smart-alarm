# Smart Alarm

Чёрный умный будильник для Android.

- Свой звук: любой файл (mp3, ogg, wav, m4a, flac…)
- Выключение: тапы по случайным кружкам (3–10)
- Без неона, только чёрный UI
- Точный будильник + вибрация

## Установка
1. Установить APK
2. Разрешить уведомления и точные будильники
3. Выбрать время, звук, сложность → Сохранить
